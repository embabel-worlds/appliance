This appliance provides two MCP endpoints. They use the same token but expose
different tools:

    /mcp/chat    For chat clients such as Claude Desktop and Open WebUI. It can
                 search your graph and documents, use saved views, and access
                 the assistant's memory.

    /mcp/code    For coding agents such as Claude Code and Codex. It can install
                 and author realms, inspect connected systems, and create views
                 and handlers.

Plain /mcp is the same as /mcp/chat and is the address most chat clients expect.

The token stays on this machine and becomes active after setup restarts the
appliance.
