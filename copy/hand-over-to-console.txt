That page is the Worlds console. It asks for the account you sign in with, a
model provider key, and whether coding agents can reach this world — and it
asks there rather than in this terminal because it can do more with the
answers. A key is checked against the provider as you paste it, so a wrong one
is wrong immediately instead of at the end. A username is suggested from your
name. And the world it builds for you says what it is doing while it does it,
which on a first run is about ninety seconds of cloning.

Nothing is configured yet, so nothing is lost if you close the page. The link
works until setup is finished.
